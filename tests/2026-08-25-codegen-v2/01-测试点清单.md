## 二、配置项（generate.yaml 全配置项）

| 编号 | 测试点 | 说明 |
| --- | --- | --- |
| TP-CFG-01 | 项目命名 | projectPrefix / groupId / projectArtifactPrefix / basePackage 必填校验、非法值（连字符、大写）拦截 |
| TP-CFG-02 | projectStyle / moduleLayout | 合法组合 monolith:flat / aggregated / maven-module；非法值报错；microservice 报“暂未支持” |
| TP-CFG-03 | modules 列表 | 模块解析，表级 module 关联校验（未声明模块告警） |
| TP-CFG-04 | jdbc / outputDir | 数据库连接、输出目录、`~` 展开 |
| TP-CFG-05 | globalLogicDelete | enable=true 时 column_name / normal_value / delete_value 必填校验；表无 del_flag 列时退化为物理删除并告警 |
| TP-CFG-06 | 表级 logicDelete | 覆盖全局逻辑删除配置 |
| TP-CFG-07 | plugins | 声明 sa-token 后的行为（协议先行，第一版不落地） |
| TP-CFG-08 | tables 基础字段 | db_table_name / model_name 缺省（表名驼峰）/ model_comment 缺省（读表注释）/ module 关联 |
| TP-CFG-09 | generateController:false | 内部表不生成 web/biz 层文件 |
| TP-CFG-10 | force_create | 已存在文件：false=跳过，true=覆盖并警告 |
| TP-CFG-11 | columns.type: enum | int 族→Integer 枚举、varchar/char→String 枚举、bigint→Long；code/name 重复校验；共享枚举 |
| TP-CFG-12 | columns.type: 强制类型 | bigint→Integer 等 Convert 转换矩阵 |
| TP-CFG-13 | columns.type: json / jsonArray / jsonObject | 原始串 / List<X> / POJO 或 Map<String,Object> |
| TP-CFG-14 | sensitive + sensitiveStrategy | 脱敏列剔除规则 + 默认敏感名单（password 等） |
| TP-CFG-15 | comment | 列注释覆盖数据库注释 |

## 三、项目风格（文档 05 / 08）

| 编号 | 测试点 | 说明 |
| --- | --- | --- |
| TP-LAYOUT-01 | flat | 业务模块作为层内子包，目录结构 = 1.0 层模块 |
| TP-LAYOUT-02 | aggregated | `modules/{artifact}-{module}/` 收业务模块，包路径带 modules 前缀 |
| TP-LAYOUT-03 | maven-module | 业务模块平铺 `{artifact}-{module}/`，包路径同 aggregated |
| TP-LAYOUT-04 | microservice | 配置到即报“暂未支持”（文档声明占位） |
| TP-LAYOUT-05 | Maven 可构建性 | 三种布局生成的工程都能被 Maven 构建（含业务代码） |

## 四、生成语义（文档 07）

| 编号 | 测试点 | 说明 |
| --- | --- | --- |
| TP-GEN-01 | 命名与类型映射 | 表名→ModelName、列名→camelCase、数据库类型→Java 类型 |
| TP-GEN-02 | 敏感列 | CreateRequest 保留；QueryRequest / Response / QueryParam / Mapper 条件剔除 |
| TP-GEN-03 | 逻辑删除 SQL | char 列字面量加引号；deleteById 转 UPDATE；查询自动过滤 |
| TP-GEN-04 | 时间列 | DB 自动维护则不写；否则 INSERT/UPDATE 显式 NOW() |
| TP-GEN-05 | 复合主键 | ByKey 全键 CRUD；关联表 generateController:false 文件数 |
| TP-GEN-06 | 枚举 | DO 保持原始类型，Model/DTO 用枚举，Convertor 双向转换，同模块内只生成一次 |
| TP-GEN-07 | json 列转换 | Convertor DO↔Model 双向 JsonUtil 转换 |
| TP-GEN-08 | 强制类型转换 | Convertor DO↔Model 双向 Convert 转换 |
| TP-GEN-09 | DDL 输出 | 每张表输出 `sql/{table}.sql`（SHOW CREATE TABLE） |
| TP-GEN-10 | --validate / --structure | 校验模式不落盘；结构模式按布局生成占位文件 |
