# 代码风格与模块设计

> 说明 code-generate-template（2.0）的代码分层与模块化设计方案：三种布局模式（flat / aggregated / maven-module）各自如何拆 Maven 模块、如何计算包路径与目录结构。
> 层表按 aiplatform 真实文件集校准，示例模型名统一为 `ChatMessage`（无前缀）。

---

## 一、布局模式总览

### 1.1 项目风格与模块样式

第一级：项目风格

| 选项值 | 显示名称 | 说明 |
| :--- | :--- | :--- |
| `monolith` | 单体风格 | 所有代码在同一个项目/仓库中，统一部署 |
| `microservice` | 微服务风格 | 每个业务域独立项目/仓库，独立部署（暂未实现） |

第二级：模块样式（联动）

| 项目风格 | 模块样式 | 显示名称 | 说明 |
| :--- | :--- | :--- | :--- |
| monolith | `flat` | 平铺式 | 不新建 Maven 模块，业务模块作为层内子包 |
| monolith | `aggregated` | 聚合式 | 业务模块拆 Maven 子项目，收在 modules/ 目录下 |
| monolith | `maven-module` | Maven 多模块 | 业务模块拆 Maven 子项目，平铺在根目录 |
| microservice | `single-repo` | 单仓多服务 | 多个服务在同一 Git 仓库，各自独立部署（暂未实现） |
| microservice | `multi-repo` | 多仓多服务 | 每个服务独立 Git 仓库，独立部署（暂未实现） |

### 1.2 三种模式的核心区别

| 模式 | 是否新建 Maven 模块 | 业务模块形态 | 包路径示例 |
| :--- | :--- | :--- | :--- |
| flat | 否（1.0 结构不变） | 层内子包文件夹 | `com.jakt.aiprod.core.model.chat.domain` |
| aggregated | 是（业务模块子项目） | `modules/aiprod-chat/` 子项目 | `com.jakt.aiprod.modules.chat.web.controller` |
| maven-module | 是（业务模块子项目） | `aiprod-chat/` 子项目（平铺） | `com.jakt.aiprod.modules.chat.web.controller` |

> 共享层（common）三种模式一致：始终是独立共享模块/包（`{basePackage}.common.*`），不挂业务模块；共享模型、公用异常码、插件代码统一放 `common-framework` / `common-util`。

## 二、包路径与命名映射

### 2.1 核心规则

```text
业务层包路径 = {basePackage} + {布局前缀} + {业务模块} + {层包} + {子包}
共享层包路径 = {basePackage}.common.{子包}
输出目录     = {outputDir} + {模块根目录} + /src/main/java/ + {包路径转文件路径}
```

布局参数：

| 模式 | 布局前缀 | 模块根目录（业务层） |
| :--- | :--- | :--- |
| flat | 空 | 1.0 层模块（common/dal、core/model、web…），业务模块为层内子包 |
| aggregated | `modules` | `{outputDir}/modules/{projectArtifactPrefix}-{module}/` |
| maven-module | `modules` | `{outputDir}/{projectArtifactPrefix}-{module}/`（平铺，仅包路径带 modules 前缀） |

> `module` 可空：flat 下不填 = 业务层路径不含业务模块段（`{basePackage}.{层包}.{子包}`，等价 1.0 原样）；aggregated / maven-module 下业务代码按模块落入对应子项目。

### 2.2 各层路径明细（aiplatform 真实文件集）

以 flat、`module=chat` 为例（`module` 为空时业务模块段消失，即 1.0 原样路径）：

| 层级 | 子包 | 类名规则 | flat 路径示例 |
| :--- | :--- | :--- | :--- |
| common.dal.dataobject | dataobject | `{ModelName}DO` | `common/dal/src/main/java/com/jakt/aiprod/common/dal/dataobject/ChatMessageDO.java` |
| common.dal.mapper | mapper | `{ModelName}Mapper` | `common/dal/src/main/java/com/jakt/aiprod/common/dal/mapper/ChatMessageMapper.java` |
| common.dal.mapper.xml | mapper（resources） | `{ModelName}Mapper.xml` | `common/dal/src/main/resources/mapper/ChatMessageMapper.xml` |
| common.dal.query | query | `{ModelName}DalQuery` | `common/dal/src/main/java/com/jakt/aiprod/common/dal/query/ChatMessageDalQuery.java` |
| core-model.domain | domain | `{ModelName}` | `core/model/src/main/java/com/jakt/aiprod/core/model/chat/domain/ChatMessage.java` |
| core-model.param | param | `{ModelName}QueryParam` | `core/model/src/main/java/com/jakt/aiprod/core/model/chat/param/ChatMessageQueryParam.java` |
| core-repository | repository | `{ModelName}Repository` | `core/repository/src/main/java/com/jakt/aiprod/core/repository/chat/repository/ChatMessageRepository.java` |
| core-repository.impl | impl | `{ModelName}RepositoryImpl` | `core/repository/src/main/java/com/jakt/aiprod/core/repository/chat/repository/impl/ChatMessageRepositoryImpl.java` |

> aggregated / maven-module 下，业务层文件落在业务模块子项目内，包路径按 2.1 公式替换：两种模式包路径一致（`com.jakt.aiprod.modules.chat.web.controller.ChatMessageController`），仅目录位置不同（aggregated 在 `modules/aiprod-chat/`，maven-module 平铺 `aiprod-chat/`）；common 行两种模式一致。

### 2.3 三种模式的目录结构

flat（平铺式，不新建 Maven 模块）：

```text
{outputDir}/
├── common/
│   ├── dal/src/main/java/com/jakt/aiprod/common/dal/        # dataobject / mapper / query
│   ├── integration/src/main/java/com/jakt/aiprod/common/integration/
│   └── util/src/main/java/com/jakt/aiprod/common/util/
├── core/
│   ├── model/src/main/java/com/jakt/aiprod/core/model/      # chat|auth|ai → domain / param
│   ├── repository/src/main/java/com/jakt/aiprod/core/repository/  # chat|auth|ai → repository / impl / convertor
│   └── service/src/main/java/com/jakt/aiprod/core/service/  # chat|auth|ai → service / impl
├── biz/service-impl/src/main/java/com/jakt/aiprod/biz/service/   # chat|auth|ai → service / impl
├── web/src/main/java/com/jakt/aiprod/web/                   # chat|auth|ai → controller / checker / param / result / assembler
└── bootstrap/src/main/java/com/jakt/aiprod/bootstrap/
```

aggregated（聚合式，业务模块子项目收在 modules/ 下）：

```text
{outputDir}/
├── pom.xml
├── common/                      # 共享模块（同 flat：common/dal、common/util…）
├── modules/
│   ├── aiprod-chat/
│   │   └── src/main/java/com/jakt/aiprod/modules/chat/
│   │       ├── web/             # controller / checker / param / result / assembler
│   │       ├── core/            # model / repository / service
│   │       └── biz/             # service / impl
│   ├── aiprod-auth/…
│   └── aiprod-ai/…
└── bootstrap/
```

maven-module（业务模块子项目平铺在根下）：

```text
{outputDir}/
├── pom.xml
├── common/                      # 共享模块
├── aiprod-chat/
│   └── src/main/java/com/jakt/aiprod/modules/chat/
│       ├── web/                 # controller / checker / param / result / assembler
│       ├── core/                # model / repository / service
│       └── biz/                 # service / impl
├── aiprod-auth/…
├── aiprod-ai/…
└── bootstrap/
```

### 2.4 路径映射速查表

| 模式 | 模块根目录 | 包路径前缀（业务层） | Application |
| :--- | :--- | :--- | :--- |
| flat | 1.0 层模块（不新建） | `{basePackage}.{层包}.{module}` | 1 个 |
| aggregated | `{outputDir}/modules/{projectArtifactPrefix}-{module}/src/main/java` | `{basePackage}.modules.{module}.{层包}` | 1 个 |
| maven-module | `{outputDir}/{projectArtifactPrefix}-{module}/src/main/java` | `{basePackage}.modules.{module}.{层包}` | 1 个 |

### 2.5 路径生成伪代码（统一口径）

```java
public PathSpec resolve(String layerPackage, String sub, String module) {
    String pkg;
    if (layerPackage.startsWith("common.")) {
        // 共享层不挂业务模块
        pkg = basePackage + "." + layerPackage + "." + sub;
    } else if (isBlank(module)) {
        // 未分配业务模块：flat 等价 1.0 原样
        pkg = basePackage + "." + layerPackage + "." + sub;
    } else if (layout.equals("flat")) {
        pkg = basePackage + "." + layerPackage + "." + module + "." + sub;
    } else if (layout.equals("aggregated")) {
        pkg = basePackage + ".modules." + module + "." + layerPackage + "." + sub;
    } else { // maven-module
        pkg = basePackage + ".modules." + module + "." + layerPackage + "." + sub; // 与 aggregated 同包路径，仅根目录不同
    }
    Path root = moduleRootFor(layerPackage, module); // 各布局见 2.4 速查表
    return new PathSpec(root, pkg);
}
```
