## 一、场景组 A：枚举定义的生命周期

| 编号 | 用户操作 | 触发事件 | 前端行为 | 状态变化 |
| :--- | :--- | :--- | :--- | :--- |
| A1 | 点击"新增枚举"按钮 | 打开配置弹窗 | 弹窗空白状态，枚举名输入框可编辑，映射行列表为空，显示一行空映射（code + name + desc） | 无 |
| A2 | 在弹窗中填写枚举名 + 映射行 | 表单输入 | 实时校验：枚举名是否重复、code 是否重复、name 是否重复、必填项是否为空 | 无 |
| A3 | 点击弹窗"提交"按钮 | 提交枚举定义 | ① 校验所有字段合法 ② 调用接口保存 ③ 关闭弹窗 ④ 刷新枚举下拉列表 ⑤ 新枚举出现在下拉选项中 ⑥ Toast 提示"创建成功" | 新增一条枚举定义 |
| A4 | 点击弹窗"取消"按钮 | 关闭弹窗 | ① 弹窗关闭 ② 不保存任何数据 ③ 如有未保存修改，丢弃 | 无 |
| A5 | 点击弹窗右上角"X" | 关闭弹窗 | 同 A4 | 无 |
| A6 | 点击已存在枚举的"修改"按钮 | 进入编辑模式 | ① 弹窗打开并回填数据 ② 所有字段可编辑 ③ 提交按钮文案变为"保存修改" ④ 映射行可增删改 | 无 |
| A7 | 修改枚举定义后点击"保存修改" | 提交修改 | ① 校验合法 ② 调用接口更新 ③ 关闭弹窗 ④ 刷新下拉列表 ⑤ 所有引用该枚举的字段，下拉选项同步更新 ⑥ Toast 提示"修改成功" | 枚举定义更新，所有引用同步 |
| A8 | 在编辑模式下点击"取消" | 取消修改 | ① 弹窗关闭 ② 不回存修改 ③ 枚举保持原样 | 无 |
| A9 | 点击已存在枚举的"删除"按钮 | 删除枚举定义 | ① 弹出二次确认框"该枚举已被 N 个字段引用，删除后这些字段将失效，确认删除？" ② 确认后调用删除接口 ③ 删除成功后：移除下拉选项、所有引用该枚举的字段变为"未选择"状态 ④ Toast 提示"删除成功" | 枚举定义删除，所有引用变为未选择 |

## 二、场景组 B：枚举引用（字段关联）

| 编号 | 用户操作 | 触发事件 | 前端行为 | 状态变化 |
| :--- | :--- | :--- | :--- | :--- |
| B1 | 字段类型下拉选择"枚举" | 切换字段类型为枚举 | ① 显示枚举选择下拉框 ② 下拉框加载所有已配置的枚举列表 ③ 显示"新增枚举"按钮 ④ 隐藏普通类型字段的配置项 | 字段类型变为 enum |
| B2 | 从枚举下拉框中选择一个已有枚举 | 选择枚举引用 | ① 下拉框显示选中的枚举名 ② 自动回填该枚举的映射信息（只读展示，不可编辑） ③ 自动填充 codeType（从枚举定义中读取） ④ 隐藏"添加映射行"等编辑操作（引用已配置的枚举，不可在字段级修改） | 字段关联到指定枚举定义 |
| B3 | 点击"新增枚举"按钮（在字段行内） | 打开配置弹窗 | 同 A1，但弹窗标题可显示"为字段 xxx 新增枚举" | 无 |
| B4 | 在字段行内新增枚举并提交 | 新增 + 自动引用（组合操作） | ① 同 A3（创建枚举定义） ② 创建成功后，当前字段自动选中新创建的枚举 ③ 下拉框切换到新枚举 ④ 回填映射信息 | 新增枚举定义 + 当前字段关联 |
| B5 | 在字段行内取消新增枚举 | 取消操作 | 同 A4 | 无 |
| B6 | 已关联枚举的字段，切换到其他枚举 | 切换引用 | ① 下拉框切换到新枚举 ② 回填新枚举的映射信息 ③ 旧枚举的引用计数 -1，新枚举的引用计数 +1 | 引用关系变更 |
| B7 | 已关联枚举的字段，清空枚举选择 | 取消引用 | ① 下拉框变为"请选择" ② 映射信息清空 ③ 该枚举的引用计数 -1 | 引用解除 |

## 四、场景组 D：枚举定义被引用后的限制

| 编号 | 用户操作 | 触发事件 | 前端行为 | 状态变化 |
| :--- | :--- | :--- | :--- | :--- |
| D1 | 点击已被引用的枚举的"修改"按钮 | 编辑被引用的枚举 | ① 弹窗打开 ② 警告提示"该枚举已被 N 个字段引用，修改后将影响这些字段" ③ 仍可编辑全部字段 | 无 |
| D2 | 修改已被引用的枚举的 code 值 | 修改 code | ① 警告提示"修改 code 值会影响所有引用，确认修改？" ② 确认后提交保存 | 所有引用字段的显示值同步更新 |
| D3 | 修改已被引用的枚举的 name 值 | 修改 name | ① 提示"修改 name 值会影响所有引用，确认修改？" ② 确认后提交保存 | 所有引用字段的显示值同步更新 |

| D5 | 在已被引用的枚举中新增映射行 | 新增映射 | ① 无警告 ② 新增后所有引用字段自动获得新选项 | 所有引用字段的下拉选项自动增加新值 |

## 八、数据模型

```typescript
// 枚举定义
interface EnumDefinition {
  id: string;
  className: string;           // 枚举类名，如 "CommonStatusEnum"
  codeType: 'String' | 'Integer';
  mappings: EnumMapping[];
  referencedCount: number;     // 被引用次数
  createdAt: string;
  updatedAt: string;
}

// 枚举映射行
interface EnumMapping {
  code: string | number;
  name: string;               // 大写字母+下划线
  desc: string;
}

// 字段配置（在表配置中使用）
interface FieldConfig {
  fieldName: string;
  type: 'string' | 'integer' | 'enum' | '...';
  // 当 type === 'enum' 时：
  enumRef?: string;           // 引用的枚举 className，如 "CommonStatusEnum"
  // 或内联枚举（不引用已有枚举时）
  inlineEnum?: EnumDefinition;
}
```

## 十、下拉框统一交互方案（v2 新增）

### 10.1 配置项分类

| 配置面板 | 选择场景 | 数据来源 |
| :--- | :--- | :--- |
| 枚举配置（码表） | 选择 codeType | 固定值：String / Integer |
| 字段配置 | 字段类型选择 | 固定值：string / integer / enum / date / ... |
| 字段配置 | 选择已有枚举（当 type=enum 时） | 已配置的枚举列表 |
| 字段配置 | 脱敏策略选择 | 固定值：PHONE / ID_CARD / EMAIL / ... |
| 字段配置 | 查询类型选择 | 固定值：eq / like / range / ... |
| 表配置 | 选择业务域（module） | 已配置的模块列表（可动态新增） |
| 表配置 | 选择生成策略 | 固定值：controller / service / repository / ... |

### 10.2 三种下拉方案

**方案 A：标准下拉选择（固定选项）** — 适用于选项固定不变的场景

| 配置项 | 选项列表 | 交互说明 |
| :--- | :--- | :--- |
| codeType | String、Integer、Long | 标准下拉，单选，无其他操作 |
| 字段类型 | string、integer、enum、date、decimal、boolean | 标准下拉，单选，选择后联动显示后续配置 |
| 脱敏策略 | PHONE、ID_CARD、EMAIL、NAME、ADDRESS、PASSWORD | 标准下拉，单选，带预览提示 |
| 查询类型 | eq（精确）、like（模糊）、range（范围）、isNull（空判断） | 标准下拉，单选 |
| 生成策略 | controller、service、repository、model、dal、dto、test | 多选下拉（Tag 形式），每个选项带开关 |

**方案 B：下拉 + 新增（可动态扩展）** — 适用于选项可动态新增的场景

| 配置项 | 交互方式 | 说明 |
| :--- | :--- | :--- |
| 业务域（module） | 下拉选择框 + 右侧"新增"按钮 | 点击新增 → 弹出输入框 → 输入名称 → 提交后自动选中新模块 |
| 枚举引用（enumRef） | 下拉选择框 + 右侧"新增枚举"按钮 | 点击新增 → 弹出枚举配置弹窗 → 创建成功后自动选中新枚举 |

**方案 C：下拉 + 管理入口（查看/编辑/删除）** — 适用于选项需要查看详情或管理的场景

| 配置项 | 交互方式 | 说明 |
| :--- | :--- | :--- |
| 枚举引用（高级模式） | 下拉选择框 + 下拉选项右侧带"编辑"图标 | 下拉列表中每个枚举项右侧显示 ✏️ 和 🗑️ 图标，点击后进入编辑/删除 |

### 10.3 行为规范

固定值下拉框（方案 A）：

- 单选，点击展开选项列表；
- 选中后立即生效，不需额外确认；
- 选中某些值（如 enum）时，下方动态显示关联配置项。

可新增下拉框（方案 B）：

- 下拉框中显示所有已配置选项；
- 点击"新增"弹出轻量输入框（如新增业务域：名称仅支持小写字母）；
- 提交后下拉框自动刷新，并自动选中新选项。

枚举选择（方案 B + C 混合，交互最复杂）：

| 操作 | 事件 | 前端行为 |
| :--- | :--- | :--- |
| 下拉选择已有枚举 | 选中 | ① 回填映射信息（只读展示） ② 显示"✏️"编辑按钮 |
| 点击"新增枚举" | 打开弹窗 | ① 弹出枚举配置弹窗 ② 创建成功后自动选中 |
| 点击"✏️"编辑 | 打开编辑弹窗 | ① 弹出弹窗并回填数据 ② 修改后同步更新当前字段 |

### 10.4 事件驱动速查表

| 场景 | 触发事件 | 前端做什么 |
| :--- | :--- | :--- |
| 下拉框选择固定选项 | onChange | 立即更新字段类型/策略值，触发联动显示 |
| 下拉框选择可新增选项 | onChange | 更新选中值，触发联动 |
| 点击"新增"按钮 | onClick | 弹出轻量输入框（模块名/枚举名） |
| 新增提交 | onSubmit | 校验 → 保存 → 刷新下拉列表 → 自动选中新项 |
| 点击"编辑"图标（✏️） | onClick | 弹出枚举配置弹窗（回填数据） |
| 编辑提交 | onSubmit | 校验 → 更新 → 刷新下拉列表 → 同步所有引用 |
| 下拉框清空 | onClear | 解除引用关系，清空映射信息展示 |
| 字段类型切换 | onChange | 如从 enum 切到 string：隐藏枚举配置区域，清空 enumRef 值 |

### 10.5 统一组件清单（供前端抽象）

| 组件名 | 用途 | 使用场景 |
| :--- | :--- | :--- |
| ConfigSelect | 标准下拉框 | 固定选项（字段类型、脱敏策略等） |
| ConfigSelectWithAdd | 下拉框 + 新增按钮 | 业务域、枚举引用 |
| ConfigSelectWithManage | 下拉框 + 新增 + 编辑/删除入口 | 枚举引用（高级模式） |
| EnumConfigModal | 枚举配置弹窗 | 新增/编辑枚举定义 |
| ModuleAddModal | 业务域新增弹窗 | 新增业务域 |
| FieldConfigRow | 字段配置行 | 表配置中的字段列表 |
| MappingTable | 映射列表表格 | 枚举配置弹窗内的映射行列表 |

前端可将 `ConfigSelect`、`ConfigSelectWithAdd`、`ConfigSelectWithManage` 三个组件抽象出来复用，不同场景按需使用。
