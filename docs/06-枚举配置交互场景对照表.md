# 枚举配置交互场景对照表

> 版本：v1.0 | 生效日期：2026-08-23 | 用途：前端开发参考

---

## 一、场景组 A：枚举定义的生命周期

| 编号 | 用户操作 | 触发事件 | 前端行为 |
| :--- | :--- | :--- | :--- |
| A1 | 点击"新增枚举" | 打开配置弹窗 | 弹窗空白状态，一行空映射 |
| A2 | 填写枚举名 + 映射行 | 表单输入 | 实时校验：枚举名/ code/ name 重复性 |
| A3 | 点击"提交" | 提交枚举 | 校验 → 保存 → 关弹窗 → 刷新下拉 → Toast |
| A4 | 点击"取消"/"X" | 关闭弹窗 | 关弹窗，丢弃未保存数据 |
| A5 | 点击"修改" | 进入编辑模式 | 弹窗回填数据，字段可编辑 |
| A6 | 修改后点击"保存修改" | 提交修改 | 校验 → 更新 → 关弹窗 → 刷新下拉 → 同步引用 → Toast |
| A7 | 点击"删除" | 删除枚举 | 二次确认 → 删除 → 刷新下拉 → 引用变"未选择" → Toast |

---

## 二、场景组 B：枚举引用（字段关联）

| 编号 | 用户操作 | 触发事件 | 前端行为 |
| :--- | :--- | :--- | :--- |
| B1 | 字段类型选"枚举" | 类型切换 | 显示枚举下拉框 + "新增枚举"按钮 |
| B2 | 选择已有枚举 | 下拉选择 | 回填映射信息（只读）+ 自动填充 codeType |
| B3 | 点击行内"新增枚举" | 打开弹窗 | 同 A1 |
| B4 | 行内新增并提交 | 创建+关联 | 同 A3 + 当前字段自动选中新枚举 |
| B5 | 行内新增取消 | 取消 | 同 A4 |
| B6 | 切换到其他枚举 | 切换引用 | 更新字段引用，更新引用计数 |
| B7 | 清空枚举选择 | 取消引用 | 下拉变"请选择"，清除映射信息，引用计数 -1 |

---

## 三、场景组 C：映射行操作

| 编号 | 用户操作 | 触发事件 | 前端行为 |
| :--- | :--- | :--- | :--- |
| C1 | 点击"添加一行" | 新增行 | 列表末尾新增空行 |
| C2 | 点击某行"删除" | 删除行 | 移除该行 |
| C3 | 输入 code | 输入事件 | 实时校验 code 是否重复 |
| C4 | 输入 name | 输入事件 | 实时校验 name 是否重复 |
| C5 | 点击提交校验失败 | 提交触发表单校验 | 定位错误行，标红提示，阻止提交 |

---

## 四、场景组 D：被引用后的限制

| 编号 | 用户操作 | 触发事件 | 前端行为 |
| :--- | :--- | :--- | :--- |
| D1 | 修改被引用的枚举 | 编辑弹窗 | 提示"已被 N 个字段引用" |
| D2 | 修改 code 值 | 提交修改 | 警告"会影响所有引用"，确认后执行 |
| D3 | 删除被引用的映射行 | 提交删除 | 警告"该映射行被引用，引用字段将失效" |
| D4 | 新增映射行 | 提交新增 | 无警告，所有引用字段自动获得新选项 |
