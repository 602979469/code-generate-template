# 脱敏策略设计文档

> 版本：v1.0 | 生效日期：2026-08-23

---

## 一、核心原则

**"脱敏发生在系统的出口，而不是入口或内部。"**

- 数据库、领域模型、业务逻辑层 **始终保持数据的原始性**
- 只有**数据离开系统边界**（返回前端、打印日志）时才执行脱敏

---

## 二、脱敏分层

| 层级 | 数据状态 | 是否脱敏 |
| :--- | :--- | :---: |
| 数据库 | 原始数据 | ❌ |
| Repository | 原始数据 | ❌ |
| Domain Model | 原始数据 | ❌ |
| Core-Service | 原始数据 | ❌ |
| Biz | 原始数据 | ❌ |
| 日志打印 | 脱敏后 | ✅ |
| Controller 返回 | 脱敏后 | ✅ |

---

## 三、脱敏策略枚举

| 策略值 | 显示名称 | 脱敏规则 | 示例 |
| :--- | :--- | :--- | :--- |
| `NONE` | 不脱敏 | 原样输出 | `张三` → `张三` |
| `PHONE` | 手机号 | 保留前3后4 | `13812345678` → `138****5678` |
| `ID_CARD` | 身份证号 | 保留前6后4 | `110101199003071234` → `110101********1234` |
| `BANK_CARD` | 银行卡号 | 保留前4后4 | `6222***1234` |
| `EMAIL` | 邮箱 | 保留前3和域名 | `zha***@qq.com` |
| `NAME` | 姓名 | 保留姓氏 | `张**` |
| `ADDRESS` | 地址 | 保留前6字符 | `浙江省杭*****` |
| `PASSWORD` | 密码 | 完全脱敏 | `******` |
| `CUSTOM` | 自定义 | 用户自定义正则 | 自行配置 |

---

## 四、实现方式

### 响应脱敏（@JsonSerializer）

```java
@Data
public class User {
    @Sensitive(strategy = SensitiveStrategy.PHONE)
    private String phone;   // 13812345678 → JSON 输出 138****5678
}
```

### 日志脱敏（Logback Converter）

```xml
<conversionRule conversionWord="msg" converterClass="SensitiveMessageConverter"/>
```
