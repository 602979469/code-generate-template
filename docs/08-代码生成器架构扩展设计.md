# 代码生成器架构扩展设计

> 版本：v1.0 | 生效日期：2026-08-23

---

## 一、分层架构

```text
┌──────────────────────────────────────────────┐
│ 1. 配置层（用户输入）                          │
│    projectStyle: monolith | microservice      │
│    moduleLayout: flat | aggregated | maven-module │
└──────────────────────────────────────────────┘
                      ▼
┌──────────────────────────────────────────────┐
│ 2. 路径解析层（策略模式）                      │
│    PathStrategy 接口 → FlatStrategy /         │
│    AggregatedStrategy → MavenModuleStrategy / │
│    MicroserviceStrategy                       │
└──────────────────────────────────────────────┘
                      ▼
┌──────────────────────────────────────────────┐
│ 3. 模板渲染层（稳定不变）                      │
│    Controller.ftl / Service.ftl /             │
│    Repository.ftl                             │
│    模板不关心项目是单体还是微服务              │
└──────────────────────────────────────────────┘
```

---

## 二、策略接口设计

```java
public interface PathStrategy {
    String getLayoutName();
    String getModelPath(String basePackage, String module, String domain);
    String getRepositoryPath(String basePackage, String module, String domain);
    String getServicePath(String basePackage, String module, String domain);
    String getBizPath(String basePackage, String module, String domain);
    String getWebPath(String basePackage, String module, String domain);
    String getDoPath(String basePackage);
    String getMapperPath(String basePackage);
    String getBootstrapPath(String basePackage);
    String getModuleRoot(String projectRoot, String module);
}
```

---

## 三、策略实现类

| 策略类 | layout 值 | 说明 |
| :--- | :--- | :--- |
| FlatStrategy | flat | 平铺式：com.aiprod.core.model.chat.entity |
| AggregatedStrategy | aggregated | 聚合式：com.aiprod.modules.core.model.chat.entity |
| MavenModuleStrategy | maven-module | Maven 多模块：com.aiprod.chat.core.model.entity |
| MicroserviceStrategy | microservice | 微服务：独立项目 + 独立 bootstrap/pom.xml/Dockerfile |

---

## 四、新增架构风格的工作量

| 新增内容 | 需新增代码 | 需修改代码 | 工作量 |
| :--- | :--- | :--- | :--- |
| 单体 + 新样式 | 1 个 PathStrategy | 无 | 0.5 天 |
| 微服务 + 多仓库 | 1 个 PathStrategy + 额外文件生成 | 无 | 1 天 |
| Serverless/FaaS | 1 个 PathStrategy + 函数模板 | 无 | 1-2 天 |

---

## 五、设计原则

> "模板不关心项目是单体还是微服务，只关心包路径和类名。"
>
> "新增架构风格 = 新增一个 PathStrategy 实现类，核心生成逻辑零改动。"

```yaml
# 配置示例
projectStyle: monolith          # monolith | microservice
moduleLayout: flat              # flat | aggregated | maven-module

# 未来新增
projectStyle: serverless        # 只需新增 ServerlessStrategy
moduleLayout: function          # 新增 FunctionStrategy
```
