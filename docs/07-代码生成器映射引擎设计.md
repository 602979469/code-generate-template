# 代码生成器映射引擎设计

> 版本：v1.0 | 生效日期：2026-08-23

---

## 一、命名映射表

| 模块 | 类名规则 | 示例 |
| :--- | :--- | :--- |
| common-dal.do | `{ModelName}DO` | `BizChatMessageDO` |
| common-dal.mapper | `{ModelName}Mapper` | `BizChatMessageMapper` |
| core-model.entity | `{ModelName}` | `BizChatMessage` |
| core-repository.repository | `{ModelName}Repository` | `BizChatMessageRepository` |
| core-repository.repository.impl | `{ModelName}RepositoryImpl` | `BizChatMessageRepositoryImpl` |
| core-repository.converter | `{ModelName}Converter` | `BizChatMessageConverter` |
| core-service.service | `{ModelName}DomainService` | `BizChatMessageDomainService` |
| core-service.service.impl | `{ModelName}DomainServiceImpl` | `BizChatMessageDomainServiceImpl` |
| biz-service.handler | `{ModelName}BizHandler` | `BizChatMessageBizHandler` |
| biz-service.command | `{ModelName}{Action}Command` | `BizChatMessageCreateCommand` |
| biz-service.enums | `{Domain}ErrorCode` | `BizChatErrorCode` |
| web.controller | `{ModelName}Controller` | `BizChatMessageController` |
| web.dto.request | `{ModelName}{Action}Request` | `BizChatMessageCreateRequest` |
| web.dto.response | `{ModelName}Response` | `BizChatMessageResponse` |

---

## 二、命名转换规则

| 转换类型 | 规则 | 示例 |
| :--- | :--- | :--- |
| 表名 → ModelName | snake → PascalCase + prefix | `ai_chat_message` → `BizChatMessage` |
| 字段名 → Java 字段 | snake → camelCase | `create_time` → `createTime` |
| 数据库类型 → Java 类型 | 类型映射表 | `varchar` → `String`，`datetime` → `LocalDateTime` |

---

## 三、生成器核心流程

```text
读取配置
│
▼
连接数据库，读取表结构
│
▼
命名转换引擎
├── 表名 → ModelName
├── 字段名 → Java 字段
├── 数据库类型 → Java 类型
└── 衍生类名生成
│
▼
路径计算引擎
├── 根据 moduleLayout 选择策略
├── 计算各层包路径
└── 计算输出文件路径
│
▼
模板渲染
├── 组装数据模型
└── Freemarker 渲染
│
▼
文件输出
└── 按路径写入文件
```
