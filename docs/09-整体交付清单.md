## 二、核心设计决策速查

| 决策点 | 结论 |
| :--- | :--- |
| 模型名 | 无前缀：`chat_message` → `ChatMessage`（不拼 Biz） |
| 异常类 | 统一 `BizException` + ErrorCode，一个异常类 + 多个 ErrorCode 枚举 |
| 公共类归属 | `BaseModel` / `BaseEnum` / `ErrorCode` / `UserContext` 等迁到 **common-framework**（2.0 唯一结构调整） |
| 模块划分 | common 拆为 common-util / common-dal / common-framework / common-integration 四件套 |
| 应用层 | 统一 `XxxManager` / `XxxManagerImpl`（v2 替代 Handler/Command） |
| 接入层 | Controller + `XxxParamChecker` + `XxxAssembler` + `ApiTemplate`/`ApiResult` |
| 脱敏时机 | 响应序列化时 + 日志输出时，领域层保持原文；敏感列表级 `sensitive + sensitiveStrategy` 配置 |
| 项目结构 | 支持 3 种：flat / aggregated / maven-module（monolith）；microservice 占位暂未支持 |
| 扩展方式 | 策略模式（LayoutStrategy），新增布局只需新增实现类 + 注册表一行；插件协议先行 |
| 枚举配置 | `columns.type: enum` + `enum.className/values` 内联配置，Convertor 双向转换 |
| 生成语义 | insert 全字段；update 全量；updateByCondition 非空条件；findOne 唯一；软删列 deleteById 转 UPDATE |
| 防覆盖 | 已存在且未 `force_create` 跳过；`force_create: true` 覆盖并警告 |
