## 二、核心设计决策速查

| 决策点 | 结论 |
| :--- | :--- |
| 异常类 | 统一使用 `BizException`，一个异常类 + 多个 ErrorCode 枚举 |
| ErrorCode 位置 | 接口在 `core-model`，具体枚举在 `biz-service` |
| 脱敏时机 | 响应序列化时 + 日志输出时，领域层保持原文 |
| 项目结构 | 支持 3 种：flat / aggregated / maven-module |
| 扩展方式 | 策略模式，新增架构风格只需新增 PathStrategy |
| 枚举配置 | 支持全局枚举库 + 内联枚举 + refEnum 引用 |
