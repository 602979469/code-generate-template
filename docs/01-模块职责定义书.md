# 公司 Java 后端架构模块职责定义书

> 版本：v2.0 | 生效日期：2026-08-25 | 适用范围：所有新开发业务系统
> 参考基线：aiplatform（1.0）；结构、命名、模板照 1.0，v2 唯一结构调整：**core-model 的公共类迁到 common-framework**。

v2 相对 v1 的调整：

- common 由单一模块拆分为 **common-util / common-dal / common-framework / common-integration** 四个模块，common-framework 首次显式落地；
- core-model 的公共类（`BaseModel`、`BaseEnum`、`ErrorCode`、`UserContext` 等跨域共享模型/接口）迁到 **common-framework**，core-model 只保留业务 `domain / param`；
- 应用服务层统一 **XxxManager / XxxManagerImpl**（不再使用 Handler/Command）；
- web 层新增 **ParamChecker / Assembler**，接口返回统一 **ApiResult + ApiTemplate**；
- 模型名无前缀：`ai_chat_message` → `ChatMessage`（不拼 Biz 等前缀）。

## 一、Maven 模块清单

| 模块名 | 职责 | 放置内容 | 依赖 | 红线 |
| :--- | :--- | :--- | :--- | :--- |
| **common-util** | 最底层基础工具层 | AssertUtil、LoggerUtil、ConvertUtil、ParamValidator、Result/PageResult、BizTemplate/TransactionTemplate、ClientInfoUtil/ThreadPoolUtil/JsonUtil/TraceIdUtil、基础配置 | 第三方依赖 | ❌ 禁止依赖任何内部业务模块 |
| **common-dal** | 数据访问层 | DO、Mapper、Mapper.xml、DalQuery、RedisClient、持久化配置 | common-util | ❌ 禁止依赖 core-model 与业务模块；唯一允许操作数据库 |
| **common-framework** | 共享框架层（v2 新增） | BaseModel、BaseEnum、ErrorCodeEnum、AiPlatformException、UserContext、PageParam 等跨域公共类；插件代码落点 | common-util | ❌ 禁止依赖任何 core-/biz- 模块 |
| **common-integration** | 外部集成层 | 外部 HTTP/RPC 客户端、集成异常、集成配置 | common-util | ❌ 禁止依赖 core-model/common-dal |
| **core-model** | 领域模型层 | 业务 domain、业务 param、业务枚举 enums | common-util、common-framework | ❌ 禁止 Spring/MyBatis/Redis 注解 |
| **core-repository** | 仓储实现层 | Repository 接口/实现、Convertor | core-model、common-dal、common-util | ❌ 唯一允许操作 Mapper |
| **core-service** | 领域服务层 | Service 接口/实现 | core-repository、core-model、common-util、common-integration | ❌ 禁止注入 Mapper、禁止依赖 common-dal |
| **biz-service** | 应用服务层 | Manager 接口/实现 | core-service、core-model、common-util、common-framework | ❌ 禁止写具体业务规则、禁止碰仓储 |
| **web** | 接入层 | Controller、Param/Result DTO、ParamChecker、Assembler、ApiTemplate/ApiResult | biz-service、core-model、common-util、common-framework | ❌ 禁止写业务逻辑 |
| **bootstrap** | 启动层 | Application.java、application.yml | web、common-dal、common-framework | ❌ 禁止写业务代码 |

```text

flat                = {basePackage}.{module}.{层包}.{子包}

module 为空          = 路径不含业务模块段（flat 等价 1.0 原样）
```

## 三、依赖方向

主链路（自上而下逐层依赖）：

```text
web → biz-service → core-service → core-repository → common-dal
```

支撑依赖（横切共享层）：

```text
web / biz-service / core-model          ──►  common-framework  ──►  common-util
core-service                            ──►  common-integration ──►  common-util
core-model / common-dal / common-framework / common-integration ──►  common-util
```

红线：

- 依赖只能从上往下，禁止反向依赖、循环依赖；
- web 不得直接依赖 common-dal / core-repository，只能经过 biz-service；
- core-service 不得直接依赖 common-dal；
- core-model 不得依赖 Spring / MyBatis / Redis；
- common-framework 不得依赖任何 core-/biz- 模块；
- common-util 是最底层基础模块，不依赖任何内部业务模块。
