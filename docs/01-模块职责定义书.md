# 公司 Java 后端架构模块职责定义书

> 版本：v1.0 | 生效日期：2026-08-23 | 适用范围：所有新开发业务系统

---

## 一、Maven 模块清单

| 模块名 | 职责 | 放置内容 | 依赖 | 红线 |
| :--- | :--- | :--- | :--- | :--- |
| **common** | 全局共享层 | dal/、framework/、integration/、util/ | 第三方依赖 | ❌ 禁止依赖任何业务模块 |
| **core-model** | 领域模型层 | entity/、ErrorCode 接口 | common（仅 util） | ❌ 禁止 Spring/MyBatis 注解 |
| **core-repository** | 仓储实现层 | Repository 接口/实现、Converter | core-model、common-dal | ❌ 唯一允许操作 Mapper |
| **core-service** | 领域服务层 | DomainService 接口/实现 | core-repository、core-model | ❌ 禁止注入 Mapper |
| **biz-service** | 应用服务层 | Handler、Command、ErrorCode 枚举 | core-service、common-framework | ❌ 禁止写具体业务规则 |
| **web** | 接入层 | Controller、Request/Response DTO | biz-service、common-framework | ❌ 禁止写业务逻辑 |
| **bootstrap** | 启动层 | Application.java、application.yml | web、common-dal | ❌ 禁止写业务代码 |

## 三、依赖方向

主链路（自上而下逐层依赖）：

```text
web → biz-service → core-service → core-repository → common-dal
```

支撑依赖（横切共享层）：

```text
web / biz-service              ──►  common-framework  ──►  common-util
core-service / core-repository ──►  core-model        ──►  common-util
```
