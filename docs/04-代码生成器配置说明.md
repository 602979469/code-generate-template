## 一、完整配置结构

```yaml
# ============================================================
# generate.yaml — code-generate-template 配置模板（全配置项）
# 用法:
#   1) 首次运行 ./gen.sh 生成本文件与 example.sql
#   2) 先执行 example.sql 创建示例表（example_inner / example_logic / example）
#   3) 编辑项目命名与 jdbc 后运行: ./gen.sh ./generate.yaml
# ============================================================

# ---------------- 项目命名（全部必填，无默认值） ----------------

# 项目前缀（驼峰，用于启动类名），如 AiProd -> AiProdApplication

# Maven groupId
groupId: com.jakt

# artifactId/包名后缀（小写字母/数字，Java 包名不允许连字符）
projectArtifactPrefix: aiprod

# 基础包名
basePackage: com.jakt.aiprod

# ---------------- 项目架构风格（全局统一） ----------------

# 项目风格: monolith | microservice

# 模块样式: flat | aggregated | maven-module
#   flat        - 模块平铺在根包下: com.jakt.aiprod.core.model.chat.entity
#   aggregated  - 模块收在 modules/ 下: com.jakt.aiprod.modules.core.model.chat.entity
#   maven-module- 每个模块独立 Maven 子项目: com.jakt.aiprod.chat.core.model.entity
moduleLayout: flat

# ---------------- 业务模块列表（声明有哪些模块，供表关联选择） ----------------
modules:
  - name: chat
    displayName: 聊天模块
  - name: auth
    displayName: 认证模块
  - name: ai
    displayName: AI 模块

# ---------------- 数据库（配置了 tables 时必填） ----------------
jdbc:
  url: jdbc:mysql://localhost:3306/aiprod?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
  username: root
  password: "123456"

# 生成输出根目录（项目骨架 init 与表级 CRUD 的落点）
outputDir: /Users/jakt/IdeaProjects/AiProd

# ---------------- 全局逻辑删除（可选，默认不开启） ----------------
# enable: true 时 column_name / normal_value / delete_value 三项必填（前置校验）；
# 表级 tables[].logicDelete 可覆盖全局（示例见下方 example_logic）。
globalLogicDelete:
  enable: false
  column_name: del_flag
  normal_value: 0
  delete_value: 1

# ---------------- 业务表（每张表只需 db_table_name） ----------------
# model_name 缺省 = 表名驼峰（如 example_logic -> ExampleLogic）
# model_comment 缺省 = 数据库表注释（生成代码的所有注释都用它拼接）
# module: 必填，关联上方 modules 配置，决定代码生成到哪个模块
# 下方三张示例表覆盖全部可选配置项:
#   example_inner  -> generateController: false（内部表，不生成 web 层）
#   example_logic  -> logicDelete（逻辑删除，仅默认类型映射，不配置 columns）
#   example        -> force_create + columns（枚举 / json / jsonArray / jsonObject / 强制类型转换 / 表级敏感列）
tables:

  #    force_create: true 演示"内部表 + 强制覆盖"组合（危险：会覆盖该表已存在文件）
  - db_table_name: example_inner
    module: chat                          # 关联 modules 中的 chat 模块
    model_name: ExampleInner
    model_comment: 内部示例
    generateController: false
    force_create: true

  # 2) 逻辑删除表: 只做默认类型映射，不指定转换方式；deleteById 变 UPDATE
  #    仅配置 db_table_name + module，model_name/model_comment 走缺省（表名驼峰 + 数据库表注释）
  - db_table_name: example_logic
    module: auth                          # 关联 modules 中的 auth 模块
    logicDelete:
      enable: true
      column_name: del_flag
      normal_value: 0
      delete_value: 1

  # 3) 全功能表: 非逻辑删除，演示全部列级转换 + force_create
  #    force_create: true 会覆盖该表已存在文件（危险，演示用）
  - db_table_name: example
    module: ai                            # 关联 modules 中的 ai 模块
    model_name: Example
    model_comment: 示例
    force_create: true
    columns:
      # 枚举: int 列 -> UserTypeEnum，Model/DTO 用枚举，DO 保持 Integer
      # codeType 已移除，枚举 code 的类型由 values 中的 code 自动推断
      user_type:
        type: enum
        enum:
          className: UserTypeEnum
          values:
            - { code: 0, name: SYSTEM_USER, desc: 系统用户 }
            - { code: 1, name: NORMAL_USER, desc: 普通用户 }
      # 枚举: varchar 列 -> UserStatusEnum
      status:
        type: enum
        enum:
          className: UserStatusEnum
          values:
            - { code: ENABLED, name: ENABLED, desc: 启用 }
            - { code: DISABLED, name: DISABLED, desc: 停用 }
      # 强制类型转换: bigint -> Integer（Convert.toInt），也可 Long/BigDecimal/String
      login_count:
        type: Integer
      # 敏感字段: 表级配置脱敏策略（全局敏感词已移除，仅表级可配置）
      id_card:
        sensitive: true
        sensitiveStrategy: ID_CARD       # PHONE | ID_CARD | BANK_CARD | EMAIL | NAME | ADDRESS | PASSWORD | NONE
      phone:
        sensitive: true
        sensitiveStrategy: PHONE
      # jsonObject: javaObject 填目标对象类型（POJO 全限定名或 Map<String, Object>），缺省 Map<String, Object>
      # 注意: javaObject 指向的 POJO 需自己创建（如 com.jakt.aiprod.core.model.domain.Profile）
      profile:
        type: jsonObject
        javaObject: com.jakt.aiprod.core.model.domain.Profile
      # jsonArray: javaObject 填元素类型（POJO 全限定名或 String / Integer / Double 等基础类型）
      tags:
        type: jsonArray
        javaObject: com.jakt.aiprod.core.model.domain.Tag
      # json: 保持原始字符串
      extra:
        type: json
```

## 二、路径映射规则
### 2.1 核心规则

包路径由以下四个要素共同决定：

```yaml
projectStyle: monolith          # monolith | microservice（全局统一）
moduleLayout: flat              # flat | aggregated | maven-module（全局统一）
basePackage: com.jakt.aiprod    # 全局基础包名
module: chat                    # 表所属业务模块（表级配置）
```

计算公式：

```text
包路径 = {basePackage} + {路径前缀} + {module} + {分层路径} + {子包}
输出目录 = {outputDir} + {模块根目录} + /src/main/java/ + {包路径转文件路径}
```

### 2.2 三种样式对照表

| 样式 | 模块根目录 | 包路径 | 完整示例 |
| --- | --- | --- | --- |
| flat | 无（直接在项目根下） | {basePackage}.{module}.{layer}.{sub} | com.jakt.aiprod.chat.web.controller.BizChatMessageController |
| aggregated | 无（直接在项目根下） | {basePackage}.modules.{module}.{layer}.{sub} | com.jakt.aiprod.modules.chat.web.controller.BizChatMessageController |
| maven-module | {module}-module/ | {basePackage}.{module}.{layer}.{sub} | aiprod-chat-module/src/main/java/com/jakt/aiprod/chat/web/controller/BizChatMessageController |

### 2.5 路径映射速查表

| projectStyle | moduleLayout | 模块根目录 | 包路径前缀 | Application |
| --- | --- | --- | --- | --- |
| monolith | flat | {outputDir}/src/main/java | {basePackage}.{module} | 1 个 |
| monolith | aggregated | {outputDir}/src/main/java | {basePackage}.modules.{module} | 1 个 |
| monolith | maven-module | {outputDir}/{module}-module/src/main/java | {basePackage}.{module} | 1 个 |
| microservice | single-repo | {outputDir}/{module}-service/src/main/java | {basePackage}.{module} | N 个 |
| microservice | multi-repo | {module}-service/src/main/java | {basePackage}.{module} | N 个 |

### 2.6 路径生成伪代码

```java
public PathInfo resolvePath(GeneratorConfig config, TableConfig table, String layer, String sub) {
    String base = config.getBasePackage();
    String module = table.getModule();
    String projectStyle = config.getProjectStyle();
    String moduleLayout = config.getModuleLayout();

    // 1. 计算包路径
    String packagePath;
    if ("monolith".equals(projectStyle)) {
        if ("flat".equals(moduleLayout)) {
            packagePath = base + "." + module + "." + layer + "." + sub;
        } else if ("aggregated".equals(moduleLayout)) {
            packagePath = base + ".modules." + module + "." + layer + "." + sub;
        } else if ("maven-module".equals(moduleLayout)) {
            packagePath = base + "." + module + "." + layer + "." + sub;
        } else {
            throw new UnsupportedOperationException("不支持的 moduleLayout: " + moduleLayout);
        }
    } else if ("microservice".equals(projectStyle)) {
        packagePath = base + "." + module + "." + layer + "." + sub;
    } else {
        throw new UnsupportedOperationException("不支持的 projectStyle: " + projectStyle);
    }
    
    // 2. 计算文件输出路径
    String outputDir = config.getOutputDir();
    String filePath = packagePath.replace(".", "/");
    String fullPath;
    
    if ("monolith".equals(projectStyle)) {
        if ("flat".equals(moduleLayout) || "aggregated".equals(moduleLayout)) {
            fullPath = outputDir + "/src/main/java/" + filePath;
        } else if ("maven-module".equals(moduleLayout)) {
            fullPath = outputDir + "/" + module + "-module/src/main/java/" + filePath;
        }
    } else if ("microservice".equals(projectStyle)) {
        fullPath = outputDir + "/" + module + "-service/src/main/java/" + filePath;
    }
    
    return new PathInfo(packagePath, fullPath);
}
```

## 三、各配置项详解
### 3.1 项目基础信息

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| projectPrefix | string | ✅ | 项目前缀，驼峰，用于启动类名 |
| groupId | string | ✅ | Maven groupId |
| projectArtifactPrefix | string | ✅ | artifactId/包名后缀，小写字母/数字 |
| basePackage | string | ✅ | 基础包名，所有代码的根包 |
| projectStyle | string | ✅ | monolith / microservice |
| moduleLayout | string | ✅ | flat / aggregated / maven-module |
| outputDir | string | ✅ | 生成输出根目录 |

### 3.2 业务模块列表

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| name | string | ✅ | 模块唯一标识，小写字母/数字 |
| displayName | string | ✅ | 中文显示名 |

### 3.3 全局逻辑删除

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| enable | boolean | false | 是否启用逻辑删除 |
| column_name | string | del_flag | 逻辑删除字段名 |
| normal_value | int | 0 | 正常值 |
| delete_value | int | 1 | 删除值 |

### 3.4 表定义

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| db_table_name | string | ✅ | 数据库表名 |
| module | string | ✅ | 所属模块，与 modules[].name 匹配 |
| model_name | string | ❌ | 模型类名，缺省自动生成 |
| model_comment | string | ❌ | 模型注释，缺省读表注释 |
| generateController | boolean | ❌ | 是否生成 Controller，默认 true |
| force_create | boolean | ❌ | 是否强制覆盖，默认 false |
| logicDelete | object | ❌ | 覆盖全局逻辑删除 |
| columns | object | ❌ | 字段自定义配置 |

### 3.5 字段配置

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| type | string | enum / json / jsonObject / jsonArray / Integer / Long / String / BigDecimal |
| enum.className | string | 枚举类名 |
| enum.values | list | { code, name, desc } |
| sensitive | boolean | 是否脱敏 |
| sensitiveStrategy | string | PHONE / ID_CARD / BANK_CARD / EMAIL / NAME / ADDRESS / PASSWORD / NONE |
| javaObject | string | jsonObject/jsonArray 的目标 Java 类型全限定名 |
| maxLength | int | 预留：生成 @Size(max=...) |
| nullable | boolean | 预留：生成 @NotNull |
| queryable | boolean | 预留：是否支持查询 |
| queryType | string | 预留：eq / like / range |
本配置说明由架构组维护。
