# 项目风格与模块样式设计

> 版本：v1.0 | 生效日期：2026-08-23

---

## 一、双下拉框联动

### 第一级：项目风格

| 选项值 | 显示名称 | 说明 |
| :--- | :--- | :--- |
| `monolith` | 单体风格 | 所有代码在同一个项目/仓库中，统一部署 |
| `microservice` | 微服务风格 | 每个业务域独立项目/仓库，独立部署 |

### 第二级：模块样式（联动）

| 项目风格 | 模块样式 | 显示名称 | 说明 |
| :--- | :--- | :--- | :--- |
| monolith | `flat` | 平铺式 | 模块平铺在根包下，共用一个 Application |
| monolith | `aggregated` | 聚合式 | 模块收在 modules/ 目录下，共用一个 Application |
| monolith | `maven-module` | Maven 多模块 | 每个模块独立 Maven 子项目，同仓管理 |
| microservice | `single-repo` | 单仓多服务 | 多个服务在同一 Git 仓库，各自独立部署 |
| microservice | `multi-repo` | 多仓多服务 | 每个服务独立 Git 仓库，独立部署 |

## 二、目录结构对比

### flat（平铺式）

```text
src/main/java/com/jakt/aiprod/
├── common/
├── core-model/
│   ├── chat/entity/
│   ├── auth/entity/
│   └── ai/entity/
├── core-repository/
│   ├── chat/repository/
│   ├── auth/repository/
│   └── ai/repository/
├── core-service/
│   ├── chat/service/
│   ├── auth/service/
│   └── ai/service/
├── biz-service/
│   ├── chat/handler/
│   ├── auth/handler/
│   └── ai/handler/
├── web/
│   ├── chat/controller/
│   ├── auth/controller/
│   └── ai/controller/
└── bootstrap/
```

### aggregated（聚合式）

```text
src/main/java/com/jakt/aiprod/
├── common/
├── modules/
│   ├── core-model/
│   │   ├── chat/entity/
│   │   ├── auth/entity/
│   │   └── ai/entity/
│   ├── core-repository/
│   │   ├── chat/repository/
│   │   ├── auth/repository/
│   │   └── ai/repository/
│   ├── core-service/
│   │   ├── chat/service/
│   │   ├── auth/service/
│   │   └── ai/service/
│   ├── biz-service/
│   │   ├── chat/handler/
│   │   ├── auth/handler/
│   │   └── ai/handler/
│   └── web/
│       ├── chat/controller/
│       ├── auth/controller/
│       └── ai/controller/
└── bootstrap/
```

### maven-module（Maven 多模块）

```text
aiprod-parent/
├── pom.xml
├── aiprod-common/
├── aiprod-module-chat/
│   └── src/main/java/com/jakt/aiprod/chat/
│       ├── core-model/entity/
│       ├── core-repository/repository/
│       ├── core-service/service/
│       ├── biz-service/handler/
│       └── web/controller/
├── aiprod-module-auth/
├── aiprod-module-ai/
└── aiprod-bootstrap/
```
