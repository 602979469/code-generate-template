# 项目风格与模块样式设计

> 版本：v2.0 | 生效日期：2026-08-25
> 三种单体布局（flat / aggregated / maven-module）均已实现并编译验证；microservice 暂未实现（配置到即报错）。

---

## 一、布局总览

| 选项值 | 显示名称 | 说明 | 状态 |
| :--- | :--- | :--- | :---: |
| `monolith` | 单体风格 | 所有代码在同一个项目/仓库中，统一部署 | ✅ 支持 |
| `monolith` + `flat` | 平铺式 | 不新建 Maven 模块，业务模块名前置 | ✅ 支持 |
| `monolith` + `aggregated` | 聚合式 | 业务模块拆 Maven 子项目，收在 modules/ 下 | ✅ 支持 |
| `monolith` + `maven-module` | Maven 多模块 | 业务模块拆 Maven 子项目，平铺在根目录 | ✅ 支持 |
| `microservice` | 微服务风格 | 每个业务域独立项目/仓库，独立部署 | ❌ 未实现 |

> 三种布局统一走 `LayoutStrategy` / `PathResolver` 计算包路径与文件落点；差异只在 Maven 装配（见第五章）。

## 二、flat 包路径与命名映射

### 2.1 核心规则

```text
共享层包路径 = {basePackage}.common.{子包}                （不挂业务模块）
业务层包路径 = {basePackage}.{module}.{层包}.{子包}        （业务模块名前置）
module 为空  = 路径不含业务模块段（等价 1.0 原样）
输出目录     = {outputDir} + {层模块目录} + /src/main/java/ + {包路径转文件路径}
```

### 2.2 各层路径明细（aiplatform 真实文件集，module=chat）

| 层级 | 子包 | 类名规则 | flat 路径示例 |
| :--- | :--- | :--- | :--- |
| common.dal.dataobject | dataobject | `{ModelName}DO` | `common/dal/src/main/java/com/jakt/aiprod/common/dal/dataobject/ChatMessageDO.java` |
| common.dal.mapper | mapper | `{ModelName}Mapper` | `common/dal/src/main/java/com/jakt/aiprod/common/dal/mapper/ChatMessageMapper.java` |
| common.dal.mapper.xml | mapper（resources） | `{ModelName}Mapper.xml` | `common/dal/src/main/resources/mapper/ChatMessageMapper.xml` |
| common.dal.query | query | `{ModelName}DalQuery` | `common/dal/src/main/java/com/jakt/aiprod/common/dal/query/ChatMessageDalQuery.java` |
| core-model.domain | domain | `{ModelName}` | `core/model/src/main/java/com/jakt/aiprod/chat/core/model/domain/ChatMessage.java` |

| core-repository | repository | `{ModelName}Repository` | `core/repository/src/main/java/com/jakt/aiprod/chat/core/repository/repository/ChatMessageRepository.java` |

## 三、flat 目录结构（不新建 Maven 模块）

```text
{outputDir}/
├── common/
│   ├── dal/src/main/java/com/jakt/aiprod/common/dal/        # dataobject / mapper / query
│   ├── framework/src/main/java/com/jakt/aiprod/common/framework/  # BaseModel/BaseEnum/ErrorCodeEnum 等公共类
│   ├── integration/src/main/java/com/jakt/aiprod/common/integration/
│   └── util/src/main/java/com/jakt/aiprod/common/util/
├── core/
│   ├── model/src/main/java/com/jakt/aiprod/core/model/      # chat|auth|ai → domain / param / enums
│   ├── repository/src/main/java/com/jakt/aiprod/core/repository/  # chat|auth|ai → repository / impl / convertor
│   └── service/src/main/java/com/jakt/aiprod/core/service/  # chat|auth|ai → service / impl
├── biz/service-impl/src/main/java/com/jakt/aiprod/biz/service/   # chat|auth|ai → service / impl
├── web/src/main/java/com/jakt/aiprod/web/                   # chat|auth|ai → controller / checker / param / result / assembler
└── bootstrap/src/main/java/com/jakt/aiprod/bootstrap/
```

## 五、aggregated / maven-module 的 Maven 装配

两种布局中，每个业务模块是一个独立 Maven 子项目（含该模块的 web / core / biz 全部层代码），生成器按布局输出：

| 布局 | 业务模块根目录 | 包路径前缀（业务层） | 根 pom modules |
| :--- | :--- | :--- | :--- |
| aggregated | `{outputDir}/modules/{projectArtifactPrefix}-{module}/` | `{basePackage}.modules.{module}.{层包}` | `common`、`web`、`bootstrap`、`modules/{artifact}-{module}`... |
| maven-module | `{outputDir}/{projectArtifactPrefix}-{module}/`（平铺） | `{basePackage}.modules.{module}.{层包}` | `common`、`web`、`bootstrap`、`{artifact}-{module}`... |

装配要点：

- **web** 作为根级共享模块，只放共享 web 基础设施（ApiTemplate / ApiResult / BaseRequest / BaseResult / PageQueryRequest / 全局异常处理 / 日志过滤），业务 Controller 在各自业务模块内；
- 每个业务模块 pom 依赖 `common-util`、`common-framework`、`common-dal` 与 `web` 共享模块（含 spring-boot-starter-web / validation / springdoc / hutool / jackson-annotations）；
- **bootstrap** 依赖全部业务模块 + 共享模块，`@SpringBootApplication(scanBasePackages = 基础包)` 扫描 `modules.{module}` 下的 Bean，`@MapperScan` 与 `mybatis.mapper-locations` 走共享 common-dal；
- 骨架不再复制 flat 的 `biz/`、`core/` 空层模块；生成器自动产出根 pom / web pom / bootstrap pom / 各业务模块 pom（已存在跳过，不覆盖）。
